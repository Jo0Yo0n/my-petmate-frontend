Only the SVG icons used by sunshine.html are vendored; no runtime dependency.

`calendar-slash.svg`와 `prohibit.svg`는 기존 선 두께에 맞춰 직접 작성한 일정 취소·거절 표시용 SVG다. 위 Phosphor 배포물과 별도인 로컬 에셋이다.

`camera.svg`는 프로필 사진 편집 버튼에 사용하도록 기존 선 두께에 맞춰 직접 작성한 로컬 SVG다.
