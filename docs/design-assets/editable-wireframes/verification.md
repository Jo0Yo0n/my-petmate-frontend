# 화면 원본 검증

전체 와이어프레임은 HTML/CSS 원본, 시각 기준은 Sunshine이다. Sunshine 적용 범위는 로그인·회원가입·추천 목록·상세·채팅에 한정된다. 실제 앱·서버·기기 검증과 구분한다.

## 기존 작업에서 확인한 동작

- 가입의 필수 선택 미선택 시작, 개인 선택 시 성별 표시와 커플/가족 전환 시 숨김.
- 비밀번호 확인의 원문 일치·불일치·미입력 안내와 모의 가입 차단/성공. 원 비밀번호를 바꾸면 확인 결과 갱신.
- 추천의 모의 필터 → 상세 → 관심 전송 결과, 채팅 입력·전송, 약속 시트 열기·닫기.
- 390px·320px·큰 글씨의 주요 화면 배치, 입력과 보내기 버튼 및 아이콘의 중앙 정렬.

위 내용은 이전 브라우저 점검의 요약이며 정리 작업에서 모두 재실행한 결과는 아니다. 과거 전체 화면 캡처·중복 비교 자료·중간 JSON 검사 로그는 원본 유지에 필요하지 않아 삭제했다.

## 정리 후 확인

2026-10-23 정리 작업에서 다음 항목을 새로 확인했다. 캡처 PNG·중간 JSON 로그를 다시 생성하지 않았다.

- 삭제·통합 후 로컬 HTML/문서 참조 134개 검사: 없는 파일을 가리키는 링크 없음.
- 삭제한 과거 시안·보드·검증 문서·previews를 가리키는 참조가 남지 않았는지 확인.
- app.js·screens.js·sunshine.js의 Node 구문 검사와 Git 공백 검사 통과.
- 인앱 브라우저에서 전체 와이어프레임 37개와 Sunshine 6개 ID(채팅 두 예시 포함), 총 43개를 새로 열어 확인. 빈 본문·깨진 이미지 없음. 독립 화면 확인 중 오류 로그 없음.
- 파일 정리는 화면 기능·API 계약을 변경하지 않는다. 이 점검은 전체 입력·상태 전이·서버 테스트를 재실행한 결과가 아니다.

## 상태 선택기·공통 틀 정리 후 확인

2026-10-23 인앱 브라우저에서 확인했다.

- 두 진입점의 조작 패널·휴대폰 프레임·팝업 틀을 `preview-shell.js`로 통합했다.
- 추천 목록에서는 폼 오류·제출 중·채팅 실패 선택지가 비활성화된다. 지원하지 않는 상태를 URL로 요청하면 기본 상태로 표시하고 이유를 안내한다.
- 와이어프레임과 Sunshine 회원가입에서 필드 오류 안내, 제출 중 입력·버튼 비활성화를 확인했다. 채팅에서는 연결·전송 실패 안내와 전송 버튼 비활성화를 확인했다.
- 두 진입점에서 각각 37개 화면 선택·팝업 이동을 점검했다. 빈 본문·깨진 이미지·오류 로그 없음. Sunshine의 화면별 디자인 완료 범위는 기존 다섯 종류 그대로다.
- `export=1`에서 조작 패널이 숨겨지고 Sunshine 채팅 입력·전송 버튼이 표시되는 것을 확인했다.
- JS 구문 검사와 공백 검사 통과. 실제 앱·API 검증은 포함하지 않는다.

## 불필요 CSS 정리 후 확인

2026-10-23 정리 범위와 검증:

- 참조 없는 변수와 중복 별명 정의 26개, 필드 개선 전의 덮어써지는 선언 10개, HTML·JS에서 사용하지 않는 `.photo-note` 선택자 두 규칙을 삭제했다.
- CSS 파일 5개는 모두 현재 HTML에서 사용하는 의존성이므로 유지했다. 코랄 action·pressed·tint는 전체 와이어프레임에서 사용하므로 유지하며, Sunshine 디자인 기준으로 간주하지 않는다.
- 두 진입점의 로그인·회원가입·추천·상세·채팅·반려견 폼·보호자 수정·팝업과 로딩·빈 결과·오류·제출 중·큰 글씨·320px·export 조합 총 32개에서 정리 전후 브라우저의 계산된 스타일을 비교했다. 시각 속성 차이·오류 로그 없음. 미사용 변수 자체와 시간에 따라 회전하는 로딩 아이콘의 transform은 비교에서 제외했다.
- PNG를 생성하지 않았다. 공백 검사 통과. 실제 앱·API 검증은 범위에 포함하지 않는다.

## 제한

실제 iPhone의 Safe Area·키보드·사진/날짜 선택기·VoiceOver·Dynamic Type·실제 세션 복원·API 통합은 별도 검증 대상이다. 브라우저의 큰 글씨는 iOS Dynamic Type과 동일하지 않다. 서버 테스트와 마일스톤 완료 처리는 이번 정리 범위가 아니다.
