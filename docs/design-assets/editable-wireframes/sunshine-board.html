수정할 원본과 검증 범위

사진을 제외한 제목·본문·폼·버튼·탭·카드는 HTML/CSS입니다. 색상과 화면 구성은 sunshine.css, 화면별 마크업은 sunshine.js에서 수정합니다. 기존 모의 기능은 app.js를 재사용합니다.

기존 반려견 사진과 MIT 라이선스의 Phosphor 아이콘만 사용했습니다. 이미지 생성·RN 앱 구현·API 연결은 포함하지 않았습니다. 로그인·가입의 모의 성공 이동은 기존 와이어프레임과 같으며 실제 인증이 아닙니다.
