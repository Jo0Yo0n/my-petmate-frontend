# My Petmate iOS UI Foundation

## 디자인 방향

My Petmate의 MVP UI는 반려견을 관계의 주인공으로 보여주되, 보호자가 안전하고 차분하게 판단할 수 있어야 한다.

- 추천 화면은 따뜻한 자연광의 반려견 사진을 가장 먼저 보여준다.
- 사진에서 정보 영역으로 자연스럽게 이어지는 그라데이션 또는 흰색 표면을 사용한다.
- 궁합은 점수가 아니라 짧은 등급과 사람이 읽을 수 있는 이유로 설명한다.
- 인증, 입력 폼, 목록, 채팅은 iOS 시스템 UI에 가까운 차분한 구조를 사용한다.
- 장식보다 사진, 간격, 정렬, 타이포그래피로 계층을 만든다.
- 보호자의 외모, 정확한 위치, 인기 지표, 별점, 게임형 스와이프 표현은 사용하지 않는다.
- 보호자 성별·커플·가족 정보는 명시적으로 공개한 경우에만 표시하며, 비공개 값은 시각적으로 추론하게 만들지 않는다.

## 색상

### Light

| Token | Value | Use |
| --- | --- | --- |
| `accent` | `#E66A5C` | 주요 행동, 선택 상태, 궁합 강조 |
| `accentPressed` | `#CF594D` | 주요 행동 pressed |
| `accentTint` | `#FCEDEA` | 궁합 라벨, 선택 배경 |
| `background` | iOS system background | 화면 기본 배경 |
| `groupedBackground` | iOS system grouped background | 폼과 그룹 목록 |
| `surface` | `#FFFFFF` | 시트, 채팅 입력, 사진 위 정보 표면 |
| `label` | iOS label | 제목과 본문 |
| `secondaryLabel` | iOS secondary label | 보조 정보 |
| `separator` | iOS separator | 목록 구분선 |
| `danger` | iOS system red | 차단, 신고, 매칭 종료 |

### Dark

- 시스템 배경과 label 색상을 그대로 따른다.
- 포인트 색상은 `#FF8A7A`, 옅은 배경은 낮은 불투명도의 동일 계열을 사용한다.
- 사진과 흰색 정보 표면의 경계는 검은 그라데이션이 아니라 시스템 배경으로 자연스럽게 전환한다.

## 타이포그래피

iOS 시스템 글꼴과 Dynamic Type을 사용한다. 한국어는 시스템이 선택하는 Apple SD Gothic Neo 계열을 따른다.

| Role | Base size | Weight |
| --- | ---: | --- |
| Large title | 34 | Bold |
| Screen title | 28 | Bold |
| Dog name / primary identity | 30–34 | Bold |
| Section title | 20 | Semibold |
| Headline | 17 | Semibold |
| Body | 16 | Regular |
| Secondary body | 15 | Regular |
| Caption | 13 | Regular |
| Button | 17 | Semibold |

- 본문은 최소 15pt를 유지한다.
- 궁합 이유는 한 줄을 우선하고 길면 최대 두 줄까지 허용한다.
- 색상만으로 선택, 오류, 위험 상태를 구분하지 않는다.

## 간격과 레이아웃

- 기본 화면 좌우 여백: 20pt
- 밀접한 요소: 8pt
- 같은 그룹 내부: 12pt
- 그룹 사이: 24pt
- 주요 섹션 사이: 32pt
- 최소 터치 영역: 44 × 44pt
- 고정 하단 행동 영역은 Safe Area를 포함한다.
- 일반 목록은 카드 묶음 대신 한 표면 위 행과 구분선을 사용한다.

## 모서리와 깊이

- 필드와 작은 선택 컨트롤: 10–12pt
- 주요 버튼: 14–16pt
- 시트 상단: 24–28pt
- 반려견 사진: 화면 가장자리 또는 20–24pt
- 그림자는 사진 위 시트나 떠 있는 주요 행동에만 아주 약하게 사용한다.
- 중첩 카드와 모든 행의 카드화는 금지한다.

## 사진 원칙

- 추천 상세에서는 사진이 화면 높이의 약 52–58%를 차지한다.
- 눈과 얼굴을 가리지 않고 반려견의 몸짓이 읽히는 크롭을 사용한다.
- 자연광, 실제 산책 환경, 과한 보정이 없는 따뜻한 색감을 우선한다.
- 사진 위 텍스트는 최소화하고 뒤로가기와 더보기 정도만 둔다.
- 프로필 목록에서는 동일 사진을 정사각형 또는 4:5 비율로 재사용한다.

## 핵심 컴포넌트

### Compatibility label

- 숫자 퍼센트 없이 `아주 잘 맞아요`, `잘 맞아요`처럼 읽을 수 있는 등급을 표시한다.
- 옅은 코랄 배경과 포인트 아이콘을 사용할 수 있다.
- 바로 아래에 최대 세 개의 추천 이유를 둔다.

### Guardian identity

- 추천 목록과 상세에서 반려견 기본 정보 아래에 `여성 보호자`, `남성 보호자`, `커플 보호자`, `가족 보호자` 중 공개된 값 하나를 보조 정보로 표시한다.
- 공개하지 않은 후보는 `보호자 정보 비공개`로 표시한다.
- 보호자 정보는 궁합 등급보다 낮은 시각적 우선순위를 유지하고 사진이나 아바타를 추가하지 않는다.
- 공개 사용자의 선호 조건에서는 복수 선택이 가능하고 공개 후보만 추천된다는 설명을 함께 제공한다.
- 비공개 사용자는 보호자 정보 필터를 비활성화하고, 모든 추천 카드에 `보호자 정보 비공개`를 표시한다.

### Primary action

- 코랄 배경과 흰색 텍스트를 사용한다.
- 한 화면에 코랄로 채운 주요 버튼은 원칙적으로 하나만 둔다.
- 로딩 중에는 중복 입력을 막고 진행 상태를 텍스트와 함께 표현한다.

### Secondary and destructive actions

- 패스, 취소는 중립적인 시스템 버튼으로 표시한다.
- 매칭 종료, 차단, 신고는 일반 주요 행동과 분리하고 시스템 red를 사용한다.

### Lists

- 매칭과 반려견 목록은 사진, 제목, 한 줄 보조 정보, 필요한 상태만 표시한다.
- 읽지 않은 수처럼 행동에 직접 필요한 상태만 badge로 사용한다.

### Forms and sheets

- 등록·수정 폼은 SwiftUI Form/List의 그룹 구조를 따른다.
- 견종은 단일 선택 목록으로 제공하고 `믹스견`을 일반 선택지에 포함한다. 별도 믹스견 토글은 사용하지 않는다.
- 보호자 설정은 개인/커플/가족 유형, 개인일 때 여성·남성 성별, 공개 여부만 제공한다.
- 필터, 약속 제안, 확인 작업은 native bottom sheet로 연다.
- 시트의 주요 행동은 하단에 고정하되 키보드와 Safe Area를 피한다.

### Chat

- 상대 메시지는 system gray, 내 메시지는 accent 계열을 사용한다.
- 약속 제안은 채팅 메시지와 구분되는 구조화된 카드이지만 카드 안에 카드를 만들지 않는다.
- 종료된 약속 카드에는 한 번만 `평가하기`를 노출하고, 평가는 비공개임을 시트 안에서 짧게 설명한다.
- 연결 상태와 전송 실패는 메시지 가까이에서 설명한다.

## 모션과 피드백

- 화면 전환과 시트는 iOS 기본 애니메이션을 우선한다.
- 관심 처리와 매칭 성사에는 짧은 scale/fade 피드백만 사용한다.
- 과한 confetti, 진동 반복, 카드 날리기 효과는 사용하지 않는다.
- Reduce Motion 설정을 존중한다.

## 대표 화면 확장 기준

선택된 추천 상세 시안을 기준으로 다음 화면을 같은 언어로 설계한다.

1. 로그인
2. 반려견 등록
3. 추천 목록
4. 추천 상세
5. 선호 조건 시트
6. 매칭 목록
7. 채팅
8. 약속 제안 시트
9. 약속 후 평가 시트
10. 보호자 정보 공개 설정
