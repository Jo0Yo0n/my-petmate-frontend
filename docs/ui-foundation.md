# My Petmate UI Foundation — Sunshine

현재 HTML/CSS 시안의 시각 기준이다. 아래 수치는 CSS px 기준이며 실제 iOS point나 기기 검증을 마친 값이 아니다. 화면별 동작은 [화면 정의](screen-definition.md), 실제 스타일은 [Sunshine CSS](design-assets/editable-wireframes/styles/sunshine.css)를 참고한다.

## 색상

| 역할                  | 값        | 적용                                 |
| --------------------- | --------- | ------------------------------------ |
| 주요 행동             | `#F2CD70` | 주요 버튼·내 메시지·브랜드 포인트    |
| 주요 행동 눌림        | `#E4BA52` | 눌림·hover                           |
| 화면 배경             | `#FAF8F2` | 기본 화면·상세 정보 영역             |
| 표면                  | `#FFFEFB` | 시트·수신 메시지·행동 영역·선택 타일 |
| 주요 글자             | `#332E24` | 제목·본문·골드 배경 위 글자와 아이콘 |
| 보조 글자             | `#6C6457` | 설명·보조 정보                       |
| 선택 배경             | `#F7EDD0` | 선택 타일·궁합 영역·상태 표시        |
| 보조 강조·성공        | `#566341` | 일치 안내·성공 문구·보조 아이콘      |
| 구분선                | `#E4DED0` | 비상호작용 구분선·표면 경계          |
| 입력·선택 경계        | `#978B75` | 입력·성별 타일 경계                  |
| 포커스·선택 강조      | `#8D6B24` | 포커스·선택 테두리·보조 아이콘       |
| 오류                  | `#B42318` | 필드 오류 문구·경계·위험 링크        |
| 위험 행동             | `#D92D20` | 위험 행동 버튼 배경. 글자는 흰색     |
| 텍스트 필드 표면      | `#FFFEFA` | 텍스트 필드                          |
| 채팅 배경             | `#F3F0E7` | 대화 영역                            |
| 주요 버튼 비활성 배경 | `#E8E3D8` | 비활성 주요 버튼                     |

일반 텍스트 대비는 4.5:1 이상, 큰 글씨와 식별에 필요한 컨트롤 경계는 3:1 이상을 기준으로 한다. 배경이나 투명도가 달라지면 해당 조합을 다시 확인한다.

## 타이포그래피와 문구

HTML 시안은 `-apple-system`, `BlinkMacSystemFont`, `Apple SD Gothic Neo`, `sans-serif` 순서로 사용한다.

| 역할                       | 크기                     | 굵기             |
| -------------------------- | ------------------------ | ---------------- |
| 환영·가입 제목             | 30px                     | 700~750          |
| 추천 목록 제목             | 34px                     | 750              |
| 반려견 이름                | 목록 30px / 상세 36px    | 750              |
| 섹션 제목                  | 20~21px                  | 600~700          |
| 폼 섹션 제목               | 17px                     | 600              |
| 본문                       | 15~16px                  | 400              |
| 입력 값                    | 16px                     | 400              |
| 필드 label                 | 14px                     | 600              |
| 보조 설명·피드백           | 12~13px                  | 400              |
| 행동 버튼                  | 기본 14px / 큰 글씨 18px | 600              |
| 워드마크 부제·장식 영문·탭 | 10~11px                  | 기존 시안의 예외 |

본문 줄 높이는 글자 크기의 약 1.6~1.85배, 제목은 약 1.2~1.3배다. 큰 제목의 자간은 약 -1px이다. 필수 설명·오류·행동에는 10~11px 예외를 사용하지 않는다.

입력 label은 명사로, 행동은 `저장`, `관심 있어요`, `약속 제안`처럼 결과를 알 수 있는 말로 쓴다. 오류에는 문제와 수정 방법을 담는다.

## 간격·형태·고정 영역

| 항목                | 기준                                                             |
| ------------------- | ---------------------------------------------------------------- |
| 일반 화면 좌우 여백 | 24px. 로그인 26px, 채팅 본문 20px                                |
| 밀접한 요소         | 8~12px. 선택 타일 사이 8~10px                                    |
| 그룹 내부           | 16~20px                                                          |
| 그룹·섹션 사이      | 24~32px                                                          |
| 최소 터치 영역      | 44×44px                                                          |
| 필드                | 높이 최소 54px, 모서리 14px                                      |
| 주요 버튼           | 표면 높이 40px, 터치 영역 최소 44px, 모서리 12px, 좌우 여백 16px |
| 사진 목록           | 모서리 26px                                                      |
| 선택 타일 모서리    | 유형 18px, 성별 13px, 상태 행 17px                               |
| 팝업 모서리         | 일반 확인 24px, 시트 상단 28px                                   |
| 미리보기 프레임     | 기본 390×844px, 좁은 화면 점검 폭 320px                          |

본문과 고정된 헤더·하단 탭·하단 행동 영역은 분리하고, 본문에 하단 영역만큼 공간을 확보한다.

## 입력 필드와 선택

| 상태             | 시각 기준                                                                     |
| ---------------- | ----------------------------------------------------------------------------- |
| 텍스트 필드 기본 | 배경 `#FFFEFA`, 경계 `#978B75` 1px, 내부 여백 상하 14px·좌우 16px             |
| 포커스           | 배경 `#FFFFFF`, 경계 `#8D6B24`, 바깥 ring `#EADBB5` 3px, ring과 필드 사이 2px |
| 오류             | 경계 `#B42318` 2px. 내부 여백을 기본 상태보다 1px 줄여 크기 유지              |
| 성공 문구        | `#566341`                                                                     |
| 선택 타일        | 선택 시 배경 `#F7EDD0`, 경계 `#8D6B24` 2px, radio 점 표시                     |
| 보호자 유형      | 3열 타일                                                                      |
| 성별             | 2열 타일. 별도 바깥 배경·경계·내부 여백 없음                                  |
