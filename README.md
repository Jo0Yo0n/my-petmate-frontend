# My Petmate 프론트엔드

반려견의 산책·놀이 친구를 찾고 매칭·채팅·약속으로 연결하는 React Native·Expo 앱의 저장소다. MVP는 iPhone·한국어·밝은 모드로 진행한다.

## 어디서 시작할까

1. [MVP 계획의 현재 위치](docs/frontend-mvp-plan.md#현재-위치): 전체 단계와 지금 어디까지 왔는가.
2. [프론트 가이드](docs/frontend-guide.md): 화면·상태·API·저장·실행 도구는 어떻게 연결되는가.
3. [F0·F1 구현 계획](docs/f0-f1-implementation-plan.md): 다음 구현 단위와 완료 기준.
4. [프론트 기술 부채](docs/technical-debt.md): 서버 계약 확정 후 연결할 항목과 관련 백엔드 계획.

## 실행 안내

앱 생성 전이며 실행 가능한 앱·앱 실행 스크립트는 아직 없다. Prettier용 패키지 설정은 있다. 실행 환경과 첫 실행 기본안은 [프론트 가이드](docs/frontend-guide.md#실행-환경과-실행-방식)에 있다. 앱을 만든 뒤 실제 실행 명령을 이 절에 추가한다.

## 문서를 이어서 관리하는 방법

단계별 상태는 MVP 계획에서, 구현 단위별 상태와 완료 판정에 필요한 근거는 해당 상세 계획에서 현재 상태로 갱신한다. 미해결 항목은 관련 기능·계획 문서에서 관리한다.

## 디자인 미리보기

화면 구성과 모의 동작은 [HTML/CSS 와이어프레임](docs/design-assets/editable-wireframes/index.html), 시각 기준은 [UI Foundation](docs/ui-foundation.md)을 참고한다. 화면별 디자인 적용 범위는 [디자인 목차](docs/design-assets/editable-wireframes/sunshine-board.html), 로컬 실행 방법은 [화면 원본 안내](docs/design-assets/editable-wireframes/README.md)에서 확인한다. 시안은 실제 앱 구현과 별도다.
