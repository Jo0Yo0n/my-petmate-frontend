# My Petmate 프론트엔드

반려견의 산책·놀이 친구를 찾고 매칭·채팅·약속으로 연결하는 React Native·Expo 앱의 저장소다. MVP는 iPhone·한국어·밝은 모드로 진행한다.

## 어디서 시작할까

1. [MVP 계획의 현재 위치](docs/frontend-mvp-plan.md#현재-위치): 전체 단계와 지금 어디까지 왔는가.
2. [프론트 가이드](docs/frontend-guide.md): 화면·상태·API·저장·실행 도구는 어떻게 연결되는가.
3. [미결정 사항](docs/decisions.md): 앞으로 무엇을 확인하거나 결정해야 하는가.

## 실행 안내

앱 생성 전이며 실행 가능한 앱·패키지·스크립트는 아직 없다. 실행 환경과 첫 실행 기본안은 [프론트 가이드](docs/frontend-guide.md#실행-환경과-실행-방식)에 있다. 앱을 만든 단위에서 실제 실행 명령과 검증 결과를 이 절에 추가한다.

## 문서를 이어서 관리하는 방법

단계별 상태는 MVP 계획에서, 구현 단위별 상태와 검증 증거는 해당 상세 계획에서 갱신한다. 미결정 사항은 해당 문서에서 관리하고, 확정된 내용은 해당 담당 문서에 반영한 뒤 목록에서 제거한다.

## 디자인 미리보기

전체 화면의 구성·동작은 [HTML/CSS 와이어프레임](docs/design-assets/editable-wireframes/index.html)을 기준으로 한다. 새 화면의 디자인 기준은 [디자인 규칙 — Sunshine](docs/ui-foundation.md)을 따른다. Sunshine 적용은 로그인·회원가입·추천 목록·상세·채팅에 한정되며 나머지는 와이어프레임 단계다. [햇살 시안 5종](docs/design-assets/editable-wireframes/sunshine-board.html)과 [수정 가능한 화면 원본 안내](docs/design-assets/editable-wireframes/README.md)에서 실제 HTML/CSS·모의 동작·로컬 실행 방법을 확인한다. 앱 구현과 별도인 설계 자료다.
